Why trust the output

Guardrails, not vibes.

Real contracts only

Candidates are pre-filtered in code from the live listed chain — the AI can choose among them but can never invent an instrument.

Schema-validated

Every response is validated before it leaves the process, with a deterministic fallback engine — the service never returns unchecked model output.

Honest limits

Horizons beyond the longest listed expiry are capped and flagged, never faked. Coin-settlement conversion is always disclosed.
